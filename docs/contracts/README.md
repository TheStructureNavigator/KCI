# KCI Architecture Contracts

KCI architecture contracts define stable boundaries and invariants for Knowledge Center Intelligence. They are used to keep implementation choices aligned with the intended separation between KCC, KCI, Observers, Findings, EvidenceReferences, and future Insights.

Implementation should conform to all APPROVED contracts.

| KCI-006 | Insight | APPROVED |
| KCI-007 | Intelligence Execution | APPROVED |
| KCI-008 | Meta-Observer / Uatu | APPROVED |

## Statuses

- PROPOSED: under discussion and not yet binding.
- APPROVED: accepted as an architectural constraint for implementation.
- SUPERSEDED: replaced by a later approved contract.
